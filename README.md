# Ikaika Salud

Landing de Ikaika Salud. Astro 7 + Tailwind CSS v4 + daisyUI 5.

- Vista previa (rama `develop`): https://flopez-dev.github.io/ikaika-salud/

```sh
npm ci
npm run dev        # http://localhost:4321/ikaika-salud/
npm run test:e2e   # build + smoke tests de Playwright
```

Detalles del proyecto, reglas y flujo de ramas en [CLAUDE.md](CLAUDE.md).
